About This Visualizer

This tool loads trained EM43 models from the training log and allows you to test them interactively.

Each model was trained using genetic algorithms to solve specific computational tasks. Select a model from the dropdown to see its program, rule, and performance.

How to Use

  • The tool will try to auto-load log.csv. If that fails, manually select the CSV file
  • Select a trained model from the dropdown menu
  • Enter an input number n
  • Click "run" to see the cellular automaton in action
  • Hover over the visualization to see relative positions

Note: For automatic CSV loading, serve this page via HTTP (e.g., python -m http.server in the directory).

Tape Structure

All models use the same encoding: [program] 00 0^(n+1) R 0

The relative position ruler shows positions relative to the start of the input data (after the program and separator).
